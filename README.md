# Bready Bear

Bready Bear 是一个运行在 Windows 上的微信内容工作台，用 Tkinter 做界面，面向烘焙店这类需要每天发朋友圈、发群消息、同时在群里做简单客服的个人商家。

它不依赖微信官方 API，也不需要手机端或局域网面板。所有操作都在本机完成，通过桌面 UI 自动化操作微信 PC 客户端。

> 测试环境：Windows 10/11 + 微信 PC 4.1.x + Python 3.12。  
> 微信版本更新可能改变界面布局，遇到问题请先看截图和日志。

---

## 功能

### 朋友圈

- 3×3 图片九宫格，最多 9 张图；
- 缩略图预览、拖动排序、右键移除、双击看大图；
- 按时间排期，到点自动打开微信朋友圈发布；
- 支持保存草稿计划、立即发布、删除计划；
- 发布前会定位相机、收起“笔记”侧栏，避免点错入口；
- 发布后检查编辑框是否关闭，并检查“照片未发送”提示。

### 群消息

- 默认只发当前打开的微信群，不搜索群名，避免误点直播/工具资源；
- 可选自动搜索模式，但默认不推荐；
- 支持手动发送和定时发送；
- 群消息计划同样按账号隔离。

### 微信机器人

- 手动触发的群回复工具，不自动读取群消息；
- 可填写群友问题，用 DeepSeek 按人设生成回复；
- 生成后发送到当前微信群；
- 机器人控制台记录 AI 生成内容、发送时间、成功/失败原因；
- 机器人回复优先：自动发送会让路，避免两个操作同时抢微信。

### 多账号 / 多窗口

- 账号可设置角色：运营、机器人、两者；
- 支持把不同账号绑定到不同微信窗口；
- 运营账号负责朋友圈/群消息，机器人账号负责群回复；
- 微信 PC 一次只能登录一个号；多窗口场景需要重启微信后重新绑定窗口。

### 设置与语言

- 界面语言：中文 / English / 日本語；
- 切换语言时重建界面文本，不生成语音；
- 主题：浅色 / 深色；
- 群消息方式、图片处理等待、发表确认等待；
- 启动时最小化、开机自启动；
- 打开数据/日志目录、备份配置。

### 开发者设置

左侧“开发者”是独立入口，进入前会警告普通用户不要修改。里面放：

- 账号与角色；
- DeepSeek API 设置；
- 机器人人设；
- 测试：发群消息、只填入、朋友圈编辑框、真正发布测试、DeepSeek 人设。

没有开发者密码，只有警告提示。

## 快速开始

### 1. 安装 Python 依赖

需要 Python 3.12（64 位）。

```powershell
pip install -r requirements.txt
```

Tkinter 随 Python 安装，不需要额外 pip 包。

### 2. 启动

```text
python app.py
```

或者双击 `启动.bat`。  
如果使用仓库外的便携 Python 运行时，把 `runtime\pythonw.exe` 放在项目目录下，`启动.bat` 会自动使用它。

### 3. 配置微信

1. 在电脑上登录微信；
2. 打开“开发者 → 账号与角色”，填写账号名称、wxid、群名；
3. 给账号选择角色：
   - 运营：朋友圈/群消息；
   - 机器人：群内互动；
4. 如果开了两个微信窗口，分别给账号“选择微信窗口”；
5. 回到机器人页，点“启动微信机器人”；
6. 微信里打开目标群，再发送。

### 4. 配置 DeepSeek

在“开发者 → API 设置”填写客户自己的 DeepSeek API Key、Base URL、模型。

仓库不包含任何 API Key。Key 只保存在本机 `data/secret.json`，不会写进 `config.json`。

## 配置说明

首次运行会生成：

```text
config.json          界面/发送/启动配置
accounts.json        账号与角色
data/                本地数据、计划、图片、日志
logs/                运行日志与预览截图
```

这些文件默认被 `.gitignore` 排除，不会提交到仓库。

示例文件：

- `config.example.json`
- `accounts.example.json`

API Key 不放在 `config.json`，单独保存在 `data/secret.json`。

## 目录结构

```text

store.py            配置、账号、计划、日志、本地数据
scheduler.py        定时任务与账号/窗口调度
wechat_ui.py        微信窗口定位、朋友圈发布、图片选择
group_ui.py         微信群消息发送与输入框定位
ai.py               DeepSeek 客户端
i18n.py             中文 / English / 日本語 文本
operation.py        机器人优先的全局操作闸门
assets/             相机、朋友圈图标等模板
docs/               使用说明、架构、限制说明
```

## 限制

- 微信 PC 没有官方发送 API，本项目通过鼠标、键盘、剪贴板操作微信界面；
- 运行时不能锁屏，不能最小化到无法截图的状态；
- 微信更新可能改变按钮位置或窗口结构；
- 群机器人不会自动监听群消息，必须由人触发；
- 朋友圈和群消息自动化不能保证 100% 成功，失败会记录截图/日志；
- 同一时间只允许一个微信 UI 操作，机器人优先；
- 仅支持 Windows，不含手机端、Web 服务、QQ 模式。

## 隐私

- 配置、账号、计划、日志、截图都在本机；
- 提交前请确认 `config.json`、`accounts.json`、`data/`、`logs/` 没有被加入 Git。
