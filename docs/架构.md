# 架构

## 总览

```text
Tkinter 桌面
  ├─ 总览
  ├─ 自动发送（朋友圈 + 群消息统一队列）
  ├─ 机器人（微信群发消息 / 人设）
  ├─ 账号
  └─ 设置
        │
        ▼
   scheduler.py
        ├─ wechat_ui.py（朋友圈）
        └─ group_ui.py（群消息）
        │
        ▼
   store.py（config/accounts/plans/logs）
```

无 Web 服务、无手机端、无端口监听。

## 自动发送

统一计划模型：

```json
{
  "id": "...",
  "kind": "moment | group",
  "account_id": "acct_a",
  "scheduled_at": "2026-11-08T08:30:00+08:00",
  "status": "planned",
  "text": "手写内容",
  "images": [],
  "group": "群名（群消息时）"
}
```

状态：

`planned → publishing → sent`  
失败：`failed` / 重试回 `planned`  
账号不匹配：`waiting_account`

朋友圈必须有 1–9 张图；群消息必须有群名。

## 机器人

- 账号角色 `bot` 作为机器人账号；
- 机器人页“启动微信机器人”只是启用面板状态，并校验当前微信是否机器人账号；
- 发送只针对当前聊天；
- 人设保存在 `config.json` 的 `bot.persona`；
- AI 使用客户自己的 DeepSeek Key；
- 不读取群消息、不自动回复。

## 深色模式

`PALETTES` 提供 light/dark；`ttk.Style.map` 显式设置 Entry/Combobox 的只读、禁用状态前景与背景，避免黑字黑底。

## 体积

- 无前端资源；
- 无自动文案模块；
- 运行时去掉 AVIF、测试、idlelib、ensurepip、sqlite3 等非必需文件。
