# 使用说明

## 一、启动

双击 `启动.bat` 或桌面 `Bready Bear`。

桌面窗口，无手机端、无 QQ 模式。

## 二、开发者入口

左侧“开发者”是独立入口，没有密码；进入前会警告普通使用者不要乱改。

里面才有账号、API、人设、测试。普通使用者不需要进来。

## 三、账号角色

“账号”页给每个账号选角色：

- **运营（朋友圈/群消息）**：负责发朋友圈、发群消息；
- **机器人（群内互动）**：负责在微信群发消息/回复；
- **两者**：都可以。

建议：

```text
账号A：运营
账号B：机器人
```

右上角“操作账号”只列出运营账号；机器人账号在“机器人”页使用。

## 四、自动发送

1. “自动发送” → “新建发送”；
2. 类型：朋友圈 / 群消息；
3. 时间、账号（右上角所选运营账号）；
4. 手写内容；
5. 朋友圈加 1–9 张图；
6. 保存，或立即发布。

群消息默认只发当前微信聊天，不搜索群；先手动打开目标群。  
发送后会回读输入框：没发出去会报错，不会假成功。

## 五、微信机器人

1. 微信登录机器人账号；
2. “机器人”页点 **启动微信机器人**；
3. 微信手动打开目标群；
4. 填群友问题，或直接写内容；
5. 点“发送到微信群” / “AI 生成并发送”。

- 手动触发，不自动读群消息；
- 只发当前聊天，不搜索，不会点直播；
- 发送时提示“请不要动鼠标键盘”；
- 不想碰键鼠：开发者模式 → “只填入，自己按 Enter”。

### 开发者模式

勾选“开发者模式”才显示人设、测试、只填入。

## 六、设置

- 客户自己填 DeepSeek API Key；
- 交付包不预置 Key；
- 主题浅色/深色；
- 群消息发送方式（当前聊天，默认安全）。

## 七、多账号

微信 PC 一次只能登录一个号。

- 运营账号发朋友圈/群消息；
- 机器人账号发群互动；
- 两个账号切换使用，不是同时在线；
- 右上角切运营账号；机器人页用机器人账号；
- 发布时显示“正在操作微信，请不要动鼠标键盘”。

## 八、停止

关闭窗口，或 `停止.bat`。
