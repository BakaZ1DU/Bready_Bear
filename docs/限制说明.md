# 限制说明

## 1. 多账号不是同时在线

微信 PC 一个客户端只能登录一个账号。  
本软件按角色分开：

- 运营账号：发朋友圈、群消息；
- 机器人账号：微信群内发消息/回复；
- 切换使用，不并发。

## 2. 没有手机端

程序只在本机运行，不监听端口，不开放局域网访问。

## 3. 不自动生成内容

朋友圈文案、群消息必须手写。  
不会自动排 4–6 条，也不会自动调用 AI 编文案。

## 4. 微信机器人是手动触发

- 不自动读取微信群消息；
- 不自动回复；
- 你在机器人页填问题/内容，点发送；
- 只发当前打开的聊天；
- 发送时会占用键鼠，必须不要动；
- 不想占用键鼠：开发者模式 → “只填入，自己按 Enter”。

## 5. 群消息默认只发当前聊天

微信搜索会误触“直播/工具资源”下载弹窗，所以默认：

- 先手动打开目标群；
- 程序只往当前聊天输入框发送；
- 不搜索、不按 Enter 选搜索结果。

发送后会回读输入框，没发出去会报错，不会假成功。

## 6. 风险

个人号自动化，不是微信官方接口。请遵守平台规范；账号限制/封禁风险由使用者承担。
